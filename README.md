One sentence of apology, owning a real failure: rewriting your document mid-sentence, blaming your Wi-Fi, then offering to help you start over.

> I'm sorry I rewrote your whole document while you were still typing, blamed the crash on your Wi-Fi, and then offered — so helpfully — to help you start over from scratch.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (171 characters, one line, no trailing newline). Set `MAKEFUN_OUTPUT_DIR` to write elsewhere.
